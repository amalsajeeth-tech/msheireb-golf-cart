System Configuration

Connect Firebase · Configure EmailJS · Manage domain · Download QR code

Email Integration (EmailJS)
STEP 1 — EMAILJS SETUP

Connect Real Email Sending

Free up to 200 emails/month. Supports Gmail, Outlook, or your company SMTP (e.g. @msheireb.com).

STEP 1B — EMAIL TEMPLATES

Required EmailJS Templates

Create these 4 templates in your EmailJS dashboard. Use the variable names shown.

Template 1: sr_confirmation
→ Sent to reporter when SR submitted

Template 2: sr_new_notify
→ Sent to company + service team on new SR

Template 3: sr_work_started
→ Sent to reporter when team starts work

Template 4: sr_resolved
→ Sent to reporter + company on resolution

Template 5: sr_reopened
→ Sent when reporter rejects resolution
Database (Firebase)
STEP 2 — FIREBASE

Persistent Database

All service requests and logs stored permanently in Google Firebase. Free tier: 1GB storage, 50K reads/day.

STEP 2B — FIREBASE RULES

Firestore Security Rules

Paste these into your Firebase Console → Firestore → Rules.

rules_version = '2'; service cloud.firestore { match /databases/{db}/documents { match /service_requests/{id} { allow create: if true; allow read, update: if request.auth != null; } match /logs/{id} { allow read, write: if request.auth != null; } } }

STEP 3 — DOMAIN

Connect to msheireb.com Domain

To connect service.msheireb.com to this system:

Option A — GitHub Pages (Free)
1. Upload this HTML file to GitHub
2. Enable GitHub Pages in repo Settings
3. Add CNAME: service.msheireb.com
4. Add DNS CNAME record at your registrar

Option B — Netlify (Recommended)
1. Drag & drop file at netlify.com
2. Go to Domain settings → Add custom domain
3. Point DNS to Netlify nameservers

Option C — Company Server
Place HTML file in your web server's public folder and point subdomain DNS accordingly.

🔒 Credential Management

Security best practices:
• Use strong passwords (12+ characters)
• Change passwords every 90 days
• Never share credentials via email
• Enable 2-factor authentication when available
